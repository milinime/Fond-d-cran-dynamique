# Fond-d-cran-dynamique
Ceci est un projet de fond d'écran dynamique compatible avec lively wallpaper. Il change en fonction de l'heure et de la météo : est toujours en développement et je serai ravi que vous ajoutiez votre touche personnelle car le design est... un peu raté les codes un peu en désordre mais généré par Copilot donc fonctionnel.
